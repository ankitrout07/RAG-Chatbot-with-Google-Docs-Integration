Retrieval-Augmented Generation Chatbot

What is RAG?

Retrieval-Augmented Generation (RAG) combines an intelligent retriever with a generator so your assistant answers using the facts you provide, rather than guessing.

Tech Stack

Flask
Flask is a lightweight Python web framework used for your backend API.
LangChain
LangChain helps build LLM apps by managing prompts, chains, and retrieval.
OpenAI
OpenAI provides the GPT models used for general chat and responses.
Google APIs
Google APIs (Gemini, Docs) provide embeddings and document access.
FAISS
FAISS is a vector database library for fast similarity search over embeddings.
HTML / CSS / JS
HTML, CSS, and JavaScript power the frontend UI and interactions.

    About This Project

    This Enterprise RAG Chatbot is designed to bridge the gap between static documents and intelligent, conversational AI. By combining cutting-edge LLMs with high-performance vector retrieval (FAISS), it empowers you to securely chat with your Google Docs, PDFs, and text files with precise attribution.
